# FurFotos

Coming-soon page for [furfotos.com](https://furfotos.com), a photo and video journal of your pet’s life.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run lint
npm run build
```

Development happens in this environment. [furfotosinc/furfotos-codebase-webapp](https://github.com/furfotosinc/furfotos-codebase-webapp) is the version-control remote only. GitHub does not host the site.

Hosting will be Firebase when the app is ready to go live. `furfotos.com` is registered at GoDaddy and is still parked. Point that domain at Firebase Hosting when hosting is set up.

The address on the page is `furfotos@gmail.com`. Change it in `app/page.tsx` if you use a different inbox.
